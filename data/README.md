# CPRI Hackathon — Data Directory

This directory contains the dataset references for the CPRI State-Level Hackathon (Task 01).

## File Details
- **Filename**: `CPRI_Hackathon_Screening_Dataset_PARTICIPANT.xlsx`
- **Format**: Microsoft Excel (.xlsx)
- **Sheets**:
  - `README`: Data description and problem guidelines.
  - `Training_Data`: 1,000 records, 11 columns (includes `Reference_Parameter` and `Validity_Label`).
  - `Test_Data`: 350 records, 9 columns (input measurement parameters for evaluation).
  - `Sample_Submission`: 350 records template.

## Data Safety & Access
The dataset is intended strictly for authorized hackathon evaluation. Do not publicly commit or expose non-public access tokens, credentials, or personal information.
